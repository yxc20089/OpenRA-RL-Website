# OpenRA-RL Website

Project website for [OpenRA-RL](https://github.com/yxc20089/OpenRA-RL) — a Gymnasium-style reinforcement learning environment for the OpenRA real-time strategy engine.

**Live site**: https://yxc20089.github.io/OpenRA-RL-Website/

## Development

```bash
npm install
npm start     # Dev server at http://localhost:3000
npm run build # Production build
npm run serve # Preview production build
```

## Deployment

Automatically deployed to GitHub Pages via GitHub Actions on push to `main`.

## Built With

- [Docusaurus](https://docusaurus.io/) — Static site generator
- [GitHub Pages](https://pages.github.com/) — Hosting
